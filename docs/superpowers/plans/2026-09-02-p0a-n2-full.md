# P0-A + N2 Full Training Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and launch a memory-capped, detached all-public-data P0-A + N2 Track 1 training run.

**Architecture:** A focused trainer owns all-data loading, P0-A augmentation, 3-to-20-channel CNO initialization, gradient accumulation and checkpointing. A separate submission module reuses the exact torch feature functions and validates the official API without importing unavailable evaluation dependencies.

**Tech Stack:** Python 3.10+, PyTorch 2.2.2 CUDA container, official Track 1 v9 kit, h5py only in the training container.

**Spec:** `docs/superpowers/specs/2026-09-02-p0a-n2-full-design.md`

## Global Constraints

- Use all 82 released real PIV trajectories only; do not access private test.
- Peak allocated GPU memory must not exceed 12 GiB; wall time must not exceed 6 hours.
- Use micro-batch 4 and gradient accumulation 2; fixed last checkpoint at 6,800 optimizer updates.
- P0-A must be identical for training and submission and must not request metadata.
- Do not use target labels for full-data checkpoint or bounds selection.
